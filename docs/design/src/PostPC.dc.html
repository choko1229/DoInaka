イベントの情報を教える

教えてもらった情報をもとに、ド田舎.net がページを作ります。ページには情報元を必ず載せます。ログインなしで送れます。

情報元 必須
このページを読み取って、日時や場所を確認します。SNS の投稿は読み取れないので、Webページか写真で送ってください。
写真は情報元としてページに載ります。個人の名前や電話番号は、確認のときに隠します。
地域
全国どこの行事でも送れます。情報元から分かれば、こちらで直します。
ひとことは確認のために読みます。ページにはそのまま載せません。
[Cloudflare Turnstile]

送信すると、利用規約とプライバシーポリシーに同意したことになります。

このあとの流れ

  1. 情報を受け取ります
  2. 情報元を読み取ります(Webページなら翌朝までに)
  3. ド田舎.net が内容を確かめて、ページを作ります
  4. 情報元を付けて公開します
ログインしていれば、マイページで進み具合を見られます。

場所や体験は写真つきで

おすすめの場所(スポット)や体験談は、今まで通り写真つきで投稿できます。行事に行った写真は、そのイベントのページの「行った!」から足せます。
