# 止まっていること(blocked.md)

2026-10-11 時点。CLAUDE.md の「止まってよい3つ」(CI が3回直しても通らない・本番や利用者のデータを消す操作・秘密の値がコミットや PR に入りそう)には当たっていません。そのほかに、**私(Claude Code)の権限では進められないもの**が残っているので、理由と試したことを書きます。

## 1. 本番の AI の動作確認(完了条件3の本番の部分)
- **理由:** 本番の管理画面でモデルが「未設定」。OpenRouter の API キーとモデルの入力が要るが、キーの入力は運営者だけがする操作で、私はしてはいけない(秘密の値の入力・本番の保存操作は禁止)。
- **試したこと:** Chrome in Claude で本番の管理画面を見るだけ確認した(モデルは用途ごとにすべて「未設定」、紹介文の生成待ち 1,972件)。そのあとセッションが切れ、私にはログインできない。
- **代わりの確認:** 開発環境で、実際の OpenRouter の無料モデルで、投稿の判定と地域ページの紹介文(作成+ファクトチェック)が動くことを確認した(docs/decisions.md 2026-10-11)。
- **運営者の作業:** 設定画面でキーを入れ、「モデル一覧を取得」で用途ごとにモデルを選び、タイムアウトを60〜150秒にする(docs/manual-checks.md)。
