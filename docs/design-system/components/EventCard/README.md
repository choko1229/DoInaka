# EventCard
イベント・スポット・記事の一覧に使うカード。全体が1つのリンク。

- 上から 写真(4:3)、日付(`accent` の太字、スポットは営業情報)、タイトル(`h3`)、エリア(`ink-muted`)、タグ(`surface-sunken`)。
- 写真がないときは `surface-sunken` に `line-strong` の線画(電柱、バス停、山、稲穂など)を置く。
- 終了したイベントは日付の横に「終了」の小札(`ink-muted` の枠)。中止は `danger` の文字で「中止」。
- 面は `surface`、角は `radius-md`、影は `shadow-card` だけ。
- 利用側が渡すもの: 写真URLと代替テキスト(なければ線画の種類)、日付文字列、タイトル、エリア名、タグ、状態(予定・終了・中止)、リンク先。
