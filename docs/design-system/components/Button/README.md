# Button
ピル型のボタン。1画面に主ボタンは1つまで。

- 主: `accent` で塗り、文字は `on-accent`。投稿する、検索する、など画面の主目的。
- 副: `surface` に `line-strong` の枠、文字は `ink`。
- 小: 高さ36px。絞り込みチップや「行った!」に使う。押した状態(`aria-pressed="true"`)は `accent` の枠と文字。
- 高さ48px(小36px)、角は `radius-pill`、フォーカスは `focus` の2px実線。
- 「行った!」を押した直後だけ、横に `aside` で「おつかれさまでした」を2秒表示する。
- 利用側が渡すもの: ラベル文字、押したときの処理、必要なら件数。
