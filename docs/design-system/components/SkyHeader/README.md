# SkyHeader
ページ上部のヘッダー。空のグラデーションと山のシルエットで、いまの時間帯を見せる。

- 背景は `sky-top` から `sky-bottom` への縦グラデーション。下端に `hill` の山と、`bg` 色の地面で本文へつなぐ。
- 夜(`night`)だけ `glow` の点(蛍)を3〜5個表示する。動かさない。
- ロゴ・ナビ・キャッチは `ink`。ナビはスマホではメニューボタンにまとめる。
- トップページだけキャッチ(`display`)と手書きのひとこと(`aside`)を入れ、他のページは高さを詰める。
- 利用側が渡すもの: 現在のページ(ナビの選択状態)、ログイン状態。
