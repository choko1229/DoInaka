ド田舎.net は「何もないが、ある。」を伝える、ゆるくて少し自虐的な田舎ポータルです。全国の人が見ても「THE 田舎」と感じる空気を、時間帯と季節で移り変わる配色で表します。

## 声とことば

- 情報はまじめに、ひとことはゆるく。日時・場所・料金・注意事項は冗談を混ぜずに書く。
- 自虐は「田舎あるある」に限る。特定の地域や住民を笑いものにしない。
- 一人称は使わない。読者には「あなた」と呼びかけず、「〜しませんか」「〜どうぞ」で誘う。
- 絵文字は使わない。感情は手書き書体の `aside` スタイルで出す。
- 数字は半角、日付は「10月12日(日)」、時刻は「9:00〜16:00」。

### 自虐ひとこと集(この場面でだけ使う)

| 場面 | 文言 |
| --- | --- |
| キャッチコピー | 何もないが、ある。 |
| フッター | コンビニまで5km。でも、いいところです。 |
| 検索結果なし | 見つかりませんでした。田舎なので。条件をゆるめてみてください。 |
| 404 | この先、道がありません。引き返してください。 |
| 500 | 停電したみたいです。少し待ってからもう一度どうぞ。 |
| 読み込み中 | バスを待っています(1日3本) |
| 投稿完了 | 回覧板に載せました。確認してから公開します。 |
| 「行った!」を押した後 | おつかれさまでした |
| お気に入りが空 | まだ何もありません。田んぼと同じで、これから実ります。 |

ひとことは `aside` スタイル(手書き書体)で、本文の下か横に添える。エラーの原因や次の行動は、必ず `body` で別に書く。

## 色:時間帯 × 季節

配色は2つの軸で決まる。**時間帯が背景と文字**(テーマ)、**季節がアクセント**を担当する。16通りすべてで、本文は12:1以上、リンクとボタン文字は4.8:1以上、操作部品の枠は3:1以上を確認済み。

| テーマ | 時間(日本時間) | 空 | 地 |
| --- | --- | --- | --- |
| `morning` 朝 | 5:00〜10:00 | 霧がかった水色 | 若葉 |
| `day` 昼 | 10:00〜16:00 | 青空 | 田んぼの緑 |
| `evening` 夕 | 16:00〜19:00 | 夕焼けの橙 | 稲穂 |
| `night` 夜 | 19:00〜5:00 | 紺 | 黒い山、蛍の `glow` |

| 季節 | 月 | `accent` が指すトークン |
| --- | --- | --- |
| 春 | 3〜5月 | `accent-spring`(桜) |
| 夏 | 6〜8月 | `accent-summer`(青田) |
| 秋 | 9〜11月 | `accent-autumn`(柿・稲穂) |
| 冬 | 12〜2月 | `accent-winter`(冬の空) |

- 部品は `accent` だけを使い、`accent-spring` などを直接参照しない。季節の切り替えはアプリが `accent` の指す先を変えて行う。
- テーマは `<html data-theme>` に、季節は `<html data-season>` に入れる。サーバーが日本時間で初期値を決めて描画し、ブラウザ側で1分ごとに見直す。
- 利用者はフッターの切り替えで「自動 / 昼固定 / 夜固定」を選べる(`ThemeSwitch`)。選択はCookieに保存する。「自動」で OS がダークモードなら `night` を使う。
- 背景は `bg`、カードとフォームは `surface`、入力欄とタグは `surface-sunken`。文字は `ink`、補足は `ink-muted`。
- 主ボタンは `accent` で塗り、文字は `on-accent`。リンクは `accent` の文字色に下線。
- 状態色 `success` `warning` `danger` は必ず文言かアイコンと一緒に使う(色だけで意味を伝えない)。
- `sky-top` `sky-bottom` `hill` `glow` はヘッダーの風景専用。文字の背景に使わない。

## 文字

- ロゴ: `logo`(Yusei Magic)。手描き看板のようなマーカー体。ロゴ以外に使わない。
- 見出し: `display` `h1` `h2` `h3`(Zen Maru Gothic 700)。丸みでゆるさを出す。
- 本文: `body` `body-strong` `small` `caption`(BIZ UDPゴシック)。高齢の住民にも読みやすいユニバーサルデザイン書体。本文は16px未満にしない。
- 自虐ひとこと: `aside`(Yomogi)。手書きのメモ書き。情報には使わない。
- フォントはすべて Google Fonts から読み込み、`font-display: swap` にする。

## 余白・角・影

- スマホの左右余白は `space-4`、カードの内側も `space-4`。セクション間はスマホ `space-8`、PC `space-12`。
- 角丸はカードと画像が `radius-md`、ボタンとチップが `radius-pill`、入力欄とタグが `radius-sm`。
- 影は `shadow-card`(下1pxの線)だけ。ぼかした影、グラデーションのボタンは使わない。グラデーションはヘッダーの空だけ。

## 写真とイラスト

- 主役は投稿写真。カードの写真は4:3、詳細ページのメイン写真は16:9。角は `radius-md`。
- 写真がないときは、素朴な線画イラスト(電柱、バス停、稲穂、山、ため池、小さな鳥居)を `surface-sunken` の上に `line-strong` の線で描いて埋める。
- ヘッダーには空のグラデーションと、`hill` の山と田んぼのシルエットを置く。夜は `glow` の点(蛍)を数個だけ。
- 写真の上に文字を重ねない。重ねる場合は写真の下に別の帯を作る。

## アイコン

- 線のアイコンを1種類で統一する(線幅1.75px、角丸)。Lucide を推奨。
- 色は隣の文字と同じ(`ink` か `accent`)。アイコンだけのボタンには必ず読み上げ用のラベルを付ける。

## 操作と状態

- フォーカスは `focus` の2px実線、2pxオフセット。すべての操作部品に出す。
- タップ領域は44px以上。ボタンの高さは48px(小は36px)。
- 押せるカードは全体をリンクにし、ホバーでタイトルに下線を出す。動きは150msのフェード程度にとどめる。

## ロゴ

文字ロゴ「ド田舎.net」。「ド田舎」を `logo` 書体で `ink`、「.net」を一回り小さく `accent` で書く。左に、山と電柱を線で描いた小さな印を添える。印と文字の間は `space-2`。ヘッダーでは高さ32px、最小24px。
