# ド田舎.net シードデータ（自治体）

ド田舎.net（Laravel）の初期データ用の CSV です。
文字コードは UTF-8、改行は LF、1行目はヘッダーです。
作成日・出典の取得日: 2026-10-08

## ファイル一覧

| パス | 内容 |
|---|---|
| `municipalities_jp.csv` | 全国地方公共団体コード（都道府県・市区町村・政令市の区） |
| `kagawa_former_municipalities.csv` | 香川県の合併前の旧市町村（平成・昭和の大合併） |
| `scripts/` | 作成・検証に使った Python スクリプト |
| `raw/` | ダウンロードした元データと中間 JSON。リポジトリには総務省のファイル(`soumu_code_*.xlsx`、`soumu_gapei/`)と中間 JSON・ログ(`work/`)だけを入れている。Wikipedia の記事(`wiki/`、約23MB)、市のページ(`city/`)、イベント情報サイトのページ(`uub/`)など他サイトの HTML は再配布しないため入れていない。必要なら下の手順のスクリプトで取り直す |

### 列

| 列 | 内容 |
|---|---|
| code | 団体コード 6桁（検査数字を含む）。先頭0を保つ文字列 |
| pref_code | 都道府県コード 2桁 |
| pref_name | 都道府県名 |
| city_name | 市区町村名。都道府県の行は空 |
| pref_kana | 都道府県名の読み（全角カタカナ） |
| city_kana | 市区町村名の読み（全角カタカナ）。元データの半角カナを NFKC で変換 |
| kind | pref / designated_city / city / ward / special_ward / town / village |

kind の決め方:

- pref: 市区町村名が空の行
- designated_city: 2枚目のシートにある市（区でない行）
- ward: 2枚目のシートの「〇〇市〇〇区」の行（政令市の区）
- special_ward: 東京都の「〇〇区」
- city / town / village: 名前の末尾が「市」「町」「村」

### confidence の定義

次の3つのうち、いちばん低いものを入れています。

1. 合併の事実（日付・方式・合併先）: 2つ以上の独立した出典が一致 → high、1出典 → medium、不明 → low
2. 読み: 2出典が一致 → high、1出典 → medium、出典なし・不一致 → low
3. 現在の市町: 合併の経路と Wikipedia 記事が一致 → high、食い違い → medium

| heisei | 34 | 32 | 0 | 2 | 28 | 6 |
| showa | 150 | 20 | 130 | 0 | 110 | 40 |
| 合計 | 184 | | | | | |

confidence: high 34（平成すべて）、medium 150（昭和すべて）、low 0。

平成の行数 34 の説明:

- 1999-03-31 の香川県は 43 市町（5市38町0村）、今は 17 市町（8市9町）。
- 新設合併で生まれた市町が 8 つあります（さぬき市、東かがわ市、丸亀市、観音寺市、三豊市、まんのう町、小豆島町、綾川町）。
- 消えた市町の数 = 43 − 17 + 8 = **34**。データの行数と一致します。
- 内訳: 旧丸亀市・旧観音寺市の2市と、32町。合併しなかったのは 高松市・坂出市・善通寺市・土庄町・三木町・直島町・宇多津町・琴平町・多度津町 の9市町です（高松市は編入する側）。

### 確認しきれなかったこと・注意点

1. **昭和の150行の読みは Wikipedia 記事だけが出典です**（1出典、confidence=medium）。
   他の出典で読みを確認できていません。
   - 「（旧）長尾町」「（旧）大内町」など、同じ名前の後身の町の記事から読みを取った行があります（notes に記載）。
   - 同じ字で読みが違うものがあります: 造田村（大川郡）= ぞうたそん、造田村（綾歌郡）= そうだむら。記事どおりです。
2. **松山村・王越村の廃止日**: Wikipedia 一覧は 1955-07-01。uub.jp・坂出市「市域の変遷」・Wikipedia 個別記事は 1956-07-01（昭和31年7月1日）。**1956-07-01 を採用**しました。
3. **竜川村**: uub.jp では「龍川村」と表記。CSV は Wikipedia 一覧の「竜川村」です。正式表記は未確認です。
4. **現在の市町の食い違い（4件、medium）**
   - 竜川村（id 40）: Wikipedia 記事は「善通寺市・丸亀市」。合併の経路からは善通寺市だけ。丸亀市が入る理由は**未確認**。CSV は善通寺市。
   - 川津村（id 67）: 経路からは 坂出市・丸亀市・宇多津町（飯野村に入った一部が、さらに丸亀市か宇多津町に分かれたため）。Wikipedia 記事は 坂出市・宇多津町。CSV は記事どおり 坂出市;宇多津町。飯野村に入った部分の行き先は**他の出典で未確認**。
   - 神野村（id 118）: 記事は「まんのう町・琴平町」。記事によると大字五條の大部分が 1956年・1957年に満濃町から琴平町へ割譲。CSV は経路どおり まんのう町。
   - 井戸村（id 157）: 記事は「三木町・さぬき市」。記事によると 1959-11-01 に一部が長尾町（現さぬき市）へ編入。CSV は経路どおり 三木町。
   - 合併後の境界変更（区域の一部の移動）は、このデータでは追っていません。
5. **分割編入の内訳**: 川津村・飯野村は uub.jp の「本（大部分）／微（一部）」の区別を notes に書きました。紀伊村・象郷村は「一部」とだけあり、面積の比率は不明です。
6. 香川県庁のページ、市町村史（坂出市以外）は使っていません。

## ライセンス・利用条件

- 総務省のデータ: 総務省ホームページの「著作権について」により「公共データ利用規約（第1.0版）」に準拠して利用できます（https://www.soumu.go.jp/menu_kyotsuu/policy/tyosaku.html）。
  公開時は出典を書き、加工したことも書いてください。例:
  「出典：総務省『全国地方公共団体コード』（https://www.soumu.go.jp/denshijiti/code.html）（2026年10月8日に利用）を加工して作成」
- Wikipedia: 本文は CC BY-SA 4.0 です。このデータでは文章は使わず、名前・日付・読み・合併先などの**事実だけ**を使いました。notes の文は自分で書いたものです。
- uub.jp: 利用条件は確認していません。事実（日付・名前・告示番号）だけを使い、文章は使っていません。
- 坂出市: 事実（日付）の確認だけに使いました。
