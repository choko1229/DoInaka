# 画面デザインとの差(design-diff.md)

画面デザイン(docs/design/png)と実装の差を、ボードごとに記録します。`npm run e2e:compare`(COMPARE_DIR を指定)で、手元の画面を撮って見比べます。

| 状態 | 意味 |
| --- | --- |
| 済 | デザインに合わせた(見本データで、構成・文言・色・余白・書体を確かめた) |
| 差あり | 差が残っている(理由を書く) |
| 未 | まだ見比べていない |

## 全体の決め

- コンテンツの幅は 1200px(左右 32px の余白)。デザインの main(max-width 1200 + padding 32)に合わせた
- 見出し・ボタン・カードの角・影は、デザインシステムのトークンに合わせる
- デザインにない、法的に必要な項目(フッターの「掲載・投稿ポリシー」「Cookie の設定」)は、足したまま
- 要件定義書とデザインが食い違うとき(設計書 → 要件定義書 → 画面デザインの順で決める): トップの「人気のスポット」と「新着の記事・体験談」は、要件(F-P01: 人気・新着)に従って、PC にも出す(デザインは、スマホにだけ人気のスポットがある)

## ボード

| ボード | 状態 | メモ |
| --- | --- | --- |
| TopPC / Main(トップ) | 済 | FV のイラスト(PC は wide、スマホは card)、見出し・ひとこと(時間帯の一言つき)・検索・チップ、今週末のイベント(なければ、これからのイベント)、いまの季節のおすすめ、エリアから探す、人気のスポット、新着の記事、CTA、フッター(空の色の切り替え)。デザインの文言「集落名」などは見本データ || EventList PC/SP(イベント一覧) | 済 | 絞り込み(キーワード・いつ・エリア・複数分類)・結果見出し・一覧/カレンダー切替・番号のページ送り・スマホの行表示ともっと見る |
| EventDetailPC / EventDetail(イベント詳細) | 済 | 分類・タグ・情報元の箱・写真・日程・カレンダーに追加(.ics)・行きたい・コメントのスレッド・SPの並び替え。差: 地図の画像・参加者の写真の撮影者表記は見本データがないため未確認 |
| SpotPC / Spot(スポット詳細) | 済 | イベント詳細と同じ作り。差: 駐車場・支払いの欄(項目が仕様にない)、写真のサムネイル列 |
| RegionPC / RegionSP(地域) | 差あり | 基本情報・合併・出典・SPの並びは合わせた。差: 合併前の境界の図、紹介文の見出し分けと文末の脚注番号、旧町の「イベント N件」 |
| PrefPC / PrefSP(県) | 差あり | 市・町のグループ、四国のほかの県を合わせた。差: 県庁・市町数の行、県の形の図、旧町の件数 |
| MapPC / Map(地図) | 差あり | 左の一覧と絞り込み・右の地図・操作ボタン・ピンを作った。差: ピンのまとまり(数の丸)、スマホの下からの一覧、写真のサムネイル(座標つきの写真が未対応) |
| PostPC / Post(情報提供) | 差あり | 見出し・このあとの流れ・写真の案内・都道府県と市区町村の2列を合わせた。差: 写真の添付欄(要件でURLか写真が必要なため残した)、Turnstile の枠 |
| LoginPC / ErrorPC / AboutPC | 差あり | ロゴだけのヘッダーと縦中央(ログイン・エラー)、404の検索と2つのボタン、運営者情報の右の欄を合わせた。差: ErrorPC は夜の配色の見本(配色は時間帯で切り替わる)、Aboutの本文幅 |
